## Image Specifications

- **Format**: JPG for photos, PNG for logos/graphics
- **Quality**: 80-90% JPEG quality
- **Sizes**: Optimize for web (max 1920px width)
- **File Size**: Keep under 500KB per image
- **Alt Text**: All images should have descriptive alt attributes

## Optimization

Use tools like:
- ImageOptim (Mac)
- TinyPNG (Web)
- Photoshop Save for Web
- GIMP Export
